# Base Cut 모드 플레이북

음성·쉼·자막 타이밍은 [공통 컷편집 스킬](../../../capcut-cut-edit/SKILL.md)의 승인된 전역 기본값을 따른다. 각 자막의 첫 발음 상승을 개별 확인하고, 호흡·잡음·큰 모음 최고점으로 시작점을 대신하지 않는다. 일반 `컷편집 해줘`는 부트로더의 우선 연결에서 공통 스킬로 보내며 이 레거시 스타일 계약 인터뷰를 시작하지 않는다. 이 문서는 명시적 제작 모드 안의 `base_cut` 순서와 증빙만 정의하고, 나머지 계약·안전·피드백 규칙은 부트로더와 `run_contract.md`가 소유한다.

## 진입 조건

- 업체·제품·작업 ID, 선택 스타일, 선택 폰트가 계약에 고정돼 있다.
- 입력 자산과 출력 목적지가 해결돼 있다.
- 기존 결과 수정이나 스타일 학습이 아니라 새 기준 컷이 목적이다.

## 실행 순서

1. 계약의 identity, source revisions, 입력 허용 목록을 대조한다.
2. 발화 영상 또는 별도 음성 몽타주 중 입력 구조에 맞는 경로를 하나 고른다.
3. 음성 파형과 대본 의미 단위를 기준으로 음성·자막 경계를 확정한다.
4. 각 의미 단위에 허용된 영상 source와 source 구간을 배정한다.
5. 선택 폰트로 한 줄 본문 자막을 만들고 컷·음성·자막 기준본을 저장한다.
6. 저장본을 다시 읽어 계획과 실제 타임라인을 비교한다.
7. 모든 base gate가 통과한 기준본만 다음 모드의 입력으로 넘긴다.

**기본 컷 완료 전 장식 금지.** 효과음, BGM, 애니메이션, 전환, 화면 효과, 장식 그래픽은 base gate 통과 전 추가하지 않는다.

## 필수 산출물

- 입력 자산 지문과 source assignment 계획
- 최종 음성 권한과 파형 경계 계획
- 논리 자막·영상 컷 계획
- 저장 기준본과 역검증 보고서
- gate별 pass/fail 및 실패 코드

## 검증

- 저장본의 음성·영상·자막 구간과 source 구간이 계획에 맞는다.
- 본문 자막은 선택 폰트를 유지하고 의미 단위와 발화 경계에 맞는다.
- 누락, 겹침, 임의 source 대체, 계획 밖 트랙이 없다.
- 원본과 기존 산출물의 지문이 실행 전후 동일하다.
- 실패한 gate가 있으면 후속 스타일 단계로 넘기지 않는다.
