# Creative Translation Interview

Use this reference whenever the user points to a specific moment, supplies screenshots of an effect sequence, or requests an expression `like this`. It is intentionally product- and category-agnostic.

## Core principle

Separate four layers before prompting:

1. `script function`: what the viewer must understand, feel, or do;
2. `composition scaffold`: where elements are placed and how attention is directed;
3. `visual operator`: how the idea is emphasized or transformed over time;
4. `semantic substitution`: which target-script subjects, objects, actions, evidence, and outcomes replace the source content.

Preserve the reference's roles, spatial grammar, operator, and timing when compatible. Replace its nouns. `Same style` is never a complete mapping.

## Function and operator taxonomy

Tag each target script beat with one primary function: `hook`, `problem`, `mechanism`, `contrast`, `proof`, `authority`, `relief`, `value`, `objection`, or `cta`.

Tag each usable reference technique with one or more operators: `selective_color`, `sketch_to_color`, `contact_triggered_transform`, `path_following_fill`, `radial_spread`, `mask_reveal`, `material_morph`, `scale_exaggeration`, `macro_cutaway`, `collage_insert`, `camera_push`, or `hard_cut_rhythm`. Add a plain-language tag when none fits.

## Required mapping record

| Field | Question |
|---|---|
| target script beat | Which exact line or idea is being visualized? |
| viewer takeaway | What must the viewer understand, feel, or do after this beat? |
| selected source moment | Which reference timestamp or still best performs that function? |
| composition scaffold | What angle, crop, placement, hierarchy, layers, and motion path are reusable? |
| visual operator | What emphasis, trigger, propagation, reveal, contrast, or transformation rule is reusable? |
| target substitutions | What target subject, object/product, action, evidence, environment, and outcome replace the source roles? |
| final state | What exact visible and emotional state must the cut settle on? |
| exclusions | Which source nouns, identities, props, text, boxes, UI, borders, and transitions must not survive? |
| confidence | Is the mapping `high`, `medium`, or `low`, and why? |

## Interview rule

Ask only when an unresolved choice would materially change the scene. Ask no more than three questions per turn. Prefer these reusable questions:

1. `이 대본 구간에서 시청자가 가장 강하게 받아들여야 하는 것은 무엇인가요—문제의 심각성, 작동 원리, 전후 대비, 근거, 안도감, 가치, 행동 유도 중 어느 쪽인가요?`
2. `레퍼런스에서 반드시 가져올 핵심은 무엇인가요—구도, 그림체, 선택 색상, 접촉 후 변화, 특정 이동 경로, 급격한 리빌, 카메라 움직임 중 어느 것인가요?`
3. `새 영상에서 등장할 대상·제품 또는 오브젝트의 행동·마지막 화면 상태·표현 강도를 어떻게 정할까요?`

Do not ask when the conversation already answers the question. If the user says `알아서`, infer the most script-logical mapping, mark the assumption and confidence level, and expose it in Gate 1.

## Selection rule

Do not pair target and reference cuts by index. Select by this order:

1. same communicative function;
2. compatible causal operator;
3. compatible composition scaffold;
4. compatible visual medium and intensity;
5. closest pacing.

If two candidates remain materially different, interview the user. If one candidate is clearly stronger, choose it and state the reason.

## Generic translation formula

`source role structure + source composition + source operator + source timing` becomes `target-script role structure + compatible source composition + same operator + target timing adjustment`.

For example, a reference may use `low-detail initial state -> one selectively emphasized object -> contact event -> change propagates along a path -> high-clarity reveal`. The target scene should rebuild every content-bearing noun from its own script while preserving that compatible visual grammar. It must not inherit the source's body part, product, person, prop, claim, or setting unless the target script independently requires it.

## Gate 1 creative-translation brief

Use:

| 대본 구간 | 전달 기능 | 선택한 레퍼런스 컷/구간 | 가져올 연출 연산자 | 유지할 구도 | 대상용 치환 | 최종 화면 | 제외 요소 | 확신도 |
|---|---|---|---|---|---|---|---|---|

Reject a brief that contains only vague terms such as `same feel`, `similar vibe`, `reference style`, or `copy this scene`. Reject any plan that maps solely by cut number or carries source nouns into a target scene without a script-based reason.
