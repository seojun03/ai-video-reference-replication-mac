# 품질 게이트

## 목차

1. 판정 철학
2. 레퍼런스 게이트
3. 문장 후보 자동 게이트
4. 감정·속도·운율·연결성
5. 사용자 청취 게이트와 명시적 자동 QC 위임
6. 실패 상태

## 1. 판정 철학

자동 검수는 명백한 오독·누락·속도 이탈·오디오 결함을 제거하는 필터다. 자연스러움과 감정 적합성을 절대적으로 증명하는 장치는 아니다. 기본 경로에서 자동 검수와 사용자 청취 검수는 서로 대체되지 않는다. 사용자가 청취 생략과 강화 자동 QC 최종화를 명시적으로 위임할 수는 있지만, 이는 사람 청취가 완료됐다는 뜻이 아니며 남는 한계를 그대로 기록하는 별도 경로다.

통과가 불확실하면 합격으로 올리지 않는다. 측정할 수 없는 항목은 `unknown` 또는 사용자 청취 대기로 남긴다. 다만 설정된 집중 발음 게이트는 측정 불가나 구절 위치 비고유 자체를 하드 실패로 판정한다.

## 2. 레퍼런스 게이트

### 하드 실패

- 원본 레퍼런스가 75초 초과이거나 음성 스트림 없음
- 정제된 유효 발화 20초 미만
- 전사된 한글 음절 40개 미만
- 클리핑 샘플 비율 1% 초과
- 음성 스트림 없음
- Audio Isolation 또는 STT 실패
- 여러 화자 또는 권한 미확인

### 경고

- 유효 발화 20~45초
- 클리핑 샘플 비율 0.1~1%
- 분리 후에도 배경음 흔적이 청취상 명확함
- 피치·발화 속도 측정에 필요한 활성 프레임 부족

IVC 품질은 레퍼런스 품질에 제한된다. 레퍼런스가 짧거나 손상된 상태에서 “원본과 완전히 동일한 보이스”라고 보고하지 않는다.

## 3. 문장 후보 자동 게이트

모든 조건을 통과해야 `auto_passed_awaiting_user`가 된다.

| 항목 | 기준 |
|---|---|
| 한글 재전사 | 공백·문장부호 제외 편집 거리 0 |
| 추가 발화 | 한글 외 영문·숫자 등 예상하지 않은 어휘 없음 |
| 언어 판정 | 한국어 코드가 명시적으로 확인됨 |
| 평균 발화 속도 | 양쪽 측정값이 존재하고 레퍼런스 음절/초 대비 편차 10% 이하 |
| 목표 길이 | 지정된 경우 문장별 목표 대비 편차 5% 이하 |
| 클리핑 | 샘플 비율 0.1% 이하 |
| 앞 무음 | 0.35초 이하 |
| 뒤 무음 | 0.55초 이하 |
| 강제 정렬 | 원래 한글 발화문 전체 문자 정렬 및 유효한 단조 증가 타임스탬프 |
| 집중 발음 합의 | 설정된 각 구절의 문맥 없는 크롭을 3개 지정 조합으로 전사한 결과가 모두 정확히 일치 |
| 사람 청취 | 기본 경로에서 필요. 명시적 위임 경로에서는 생략 사실을 기록하고 사람 청취로 간주하지 않음 |

Forced Alignment의 loss는 기록하지만 공식적인 보편 합격 임계값이 없으므로 단독 하드 게이트로 사용하지 않는다.

Scribe가 확정된 한글 숫자 발음을 아라비아 숫자로 표기한 경우(예:
`삼 일`을 `3일`로 전사), 숫자를 가능한 한국어 읽기로 확장했을 때 전체
발화문이 정확히 일치하는 경우에만 표기 동등성을 인정한다. 다른 단어의
오독·누락·추가 발화가 함께 있으면 이 정규화를 적용하지 않는다.

같은 원칙으로 확정된 한글 알파벳 발음을 영문 약어로 표기한 경우(예:
`엠디`를 `MD`로 전사), 알파벳 이름을 한글로 확장했을 때 전체 발화문이
정확히 일치하는 경우에만 표기 동등성을 인정한다. `앤디`처럼 실제 발음이
달라진 후보는 통과시키지 않는다.

### 집중 발음 게이트

발음이 뭉개지기 쉬운 집중 구절이 설정되면 전체 문장 게이트를 통과한
후에도 다음 조건을 모두 충족해야 한다.

1. 집중 구절은 원래 발화문과 강제 정렬 문자열에 각각 정확히 한 번
   나타나야 한다.
2. 인접 단어의 음성은 제외하되, 첫 문자 바로 앞의 공백·문장부호 정렬
   경계부터 시작해 acoustic onset을 보존한다. 구절이 정렬 문자열 맨
   앞에서 시작하면 오디오 0초 경계를 사용한다. 구절이 마지막 어휘에서
   끝나면 뒤따르는 문장부호와 실제 오디오 끝까지 포함해 종성·모음의
   acoustic release를 보존하고, 그 밖에는 다음 단어의 onset이 들어오기
   전에서 자른다.
3. 잘라낸 크롭 앞뒤에는 각각 0.2초 무음만 붙인다. 집중 구절이 원본
   WAV 전체 범위를 그대로 사용하면 원래의 앞뒤 여백을 유지하고
   인위적 무음은 추가하지 않는다.
4. 같은 크롭을 Scribe v2로 다음 세 조합에서 독립 전사한다.
   - `seed=173`, `temperature=0.0`
   - `seed=907`, `temperature=0.1`
   - `seed=2027`, `temperature=0.2`
5. 세 결과 모두 한국어 언어 코드가 확인되고, 기존의 제한된 숫자·영문
   표기 정규화 뒤 원 집중 구절과 정확히 일치해야 한다.

세 결과 중 하나라도 불일치하면 다수결로 통과시키지 않는다. 구절이
없거나 여러 번 나타나 위치가 비고유한 경우, 유효한 정렬 시각이 없는
경우, 크롭 또는 전사를 측정할 수 없는 경우도 실패다. 전체 문장 STT의
정확 일치로 이 실패를 상쇄하지 않는다.

보존된 기존 후보를 `select-attempt`로 다시 선택할 때도 저장된 과거
판정만 신뢰하지 않는다. 현재 강제 정렬과 동일한 비어휘 경계 포함
크롭, 앞뒤 0.2초 무음, Scribe 3조합 전사를 다시 수행해 모두 통과한 경우에만
선택한다.

STT가 정확히 일치해도 발음이 자연스럽다는 뜻은 아니다. 반대로 자연스러운 발음을 STT가 틀릴 수도 있으므로 5회 뒤 가장 좋은 후보를 사용자에게 보여주고 멈춘다. 추가 비용 승인 질문은 하지 않는다.

## 4. 감정·속도·운율·연결성

Eleven v3 감정 태그는 문장 의미에 맞게 사용한다. 태그가 원래 문장의 의미를 바꾸거나 불필요한 웃음·한숨·효과음을 추가하면 실패다. 1분 이하 작업은 전역 태그 하나와 한 번의 coherent-block 응답을 기본으로 하며, 문장부호 휴리스틱으로 문장마다 감정 태그를 바꾸지 않는다.

별도 작업 지시가 없으면 `natural_v3_conversational_coherent` 프리셋을
적용한다. 한 문단의 연결 발화, `conversationally`, API `speed=1.15`,
`stability=0.35`가 기본이다. 발음이 정확해도 음절을 하나씩 짚거나 문장
내부 쉼이 과도해 로봇 낭독처럼 들리면 자연 발화 목표를 통과한 것으로
자동 확정하지 않는다. 이 주관 항목은 사용자의 실제 청취로 판정한다.

속도는 전체 오디오 길이를 강제 배속하는 대신 다음 순서로 맞춘다.

1. 레퍼런스 평균 음절/초 측정
2. ElevenLabs `voice_settings.speed`를 0.7~1.2 범위에서 조절
3. 다른 seed와 stability로 재생성
4. 목표 길이가 있을 때만 길이 편차 추가 검사

발음을 손상시킬 수 있는 강제 타임 스트레치는 기본 사용하지 않는다.

전체 미리보기 뒤에는 [운율·실제 오디오 QC](prosody-listening-qc.md)를
실행한다. 레퍼런스의 발화 구간 분포로 보정한 피치·에너지·리듬·스펙트럼
프록시와 인접 문장 경계를 모두 검사한다. 한 문장의 critical 지표군
하나 또는 서로 독립적인 warning 지표군 두 개가 실패하면 해당 take를
거절한다. coherent-block은 실패 문장만 splice하지 않고 전체 take를
다시 생성한다.

수치 분석은 실제 청취가 아니다. 실제 음성을 입력받는 평가 수단의
서로 다른 설정 3회가 모든 문장에서 만장일치 통과해야 다음 승인 상태로
갈 수 있다. 오디오 입력 수단이 없거나 학습된 화자·감정 판정을 사용할
수 없으면 이를 통과로 추정하지 않는다.

## 5. 사용자 청취 게이트와 명시적 자동 QC 위임

### 기본 경로: 사용자 청취

사용자는 다음을 직접 확인한다.

- 모든 단어와 조사 발음
- 받침·연음·억양
- 문장 간 연결감
- 과장되거나 부족한 감정
- 레퍼런스와 비교한 전체 말투와 평균 속도
- 불필요한 숨, 웃음, 클릭음, 왜곡

객관적 운율 QC와 실제 오디오 A/B 3회가 먼저 통과해야 한다. 전체
미리보기 승인 문구를 `job.json`과 `qc_report.json`에 기록한다. 승인 뒤 생성된 최종 파일만 전달한다.
승인은 현재 미리보기 SHA-256과 리비전에 묶는다. 부분 승인이나 이전 미리보기 승인은 최종 확정에 사용할 수 없다.

### 별도 경로: 강화 자동 QC 최종화 위임

사용자가 다음 문구로 전체 미리보기 직접 청취를 생략하고 강화 자동 QC
기반 최종화를 명시적으로 위임한 경우에만 `delegate-approve`를 사용할
수 있다.

```text
사용자가 전체 미리보기 직접 청취를 생략하고 강화 자동 검증 기반 최종화를 위임함
```

단순한 “진행해”, 자동 검수 통과, 청취 여부가 불분명한 승인 문구는 이
위임이 아니다. 위임은 현재 미리보기 SHA-256·리비전·리뷰 파일 해시에
묶이며, 모든 문장의 일반 자동 게이트와 설정된 모든 집중 발음 게이트가
통과해야 한다. 객관적 운율·경계 검사와 실제 오디오 A/B 3회 만장일치
증거도 현재 미리보기·레퍼런스·문장별 WAV 해시와 일치해야 한다.
선택 후보와 리뷰 파일이 동일한지 확인하고, 집중 발음
결과·원전사 증거 파일을 다시 읽어 현재 계획과 대조한다. 이후 전체
미리보기 WAV의 새 STT가 한글·어휘·언어 게이트를 통과한 경우에만 새
Forced Alignment를 실행하며, 전체 대본 정렬과 시각도 유효해야 한다.

미리보기와 최종본 조립은 각 문장 WAV를 mono·48kHz·24-bit PCM으로
개별 정규화한 뒤 프레임을 이어 붙여야 한다. 비트 심도가 섞인 입력을
concat demuxer에 직접 넘기지 않는다. 결과 총 프레임 수와 PCM 해시가
정규화된 문장별 PCM 순서와 다르면 실패 처리한다.

장문 전체 미리보기 STT가 정확 일치하지 않더라도 비어 있지 않은
한국어인 경우에만 문장 단위 보조 검증 후보가 된다. 장문 전사의
누락·치환 여부는 진단으로 보존한다. 선택된 문장별 WAV를 각각 공통
PCM으로 독립 디코딩해 순서대로 누적한 프레임 수·해시와 실제
미리보기의 공통 PCM 프레임 수·해시가 완전히 일치해야 한다. 실제
미리보기의 형식·클리핑·활성 음성도 통과해야 한다. 이어 모든
문장별 WAV에 서로 다른 설정의 새 STT를 3회 실행해 세 결과가 모두
정확해야 하며, 그때만 새 Forced Alignment를 실행한다. 한 검사라도
실패하면 최종화하지 않는다.

최종 `job.json`과 `qc_report.json`에는 다음을 기록한다.

- 상태: `user_delegated_auto_qc_final`
- `approval_type`: `delegated_automatic_qc`
- `human_listening_completed`: `false`

이를 사람 청취 승인이나 사용자가 발음·감정·억양을 확인한 결과로
표현하지 않는다. 자동 전사와 정렬이 자연스러움, 감정, 억양, 목소리
동일성, 미세한 음색 결함을 완전히 보증하지 못한다는 한계를 최종
보고서와 사용자 전달문에 명시한다.

## 6. 실패 상태

- `blocked_after_five_attempts`: 한 문장이 5회 자동 검수 실패
- `interrupted_recoverable`: 사용자 중단을 상태에 기록했으며 상시 생성 허용 범위와 남은 take 한도에서 선택 재개 가능
- `initialization_interrupted_new_job_required`: 레퍼런스 준비 중 중단; clone 존재 여부를 확인하고 새 작업 폴더에서 다시 시작
- `prosody_regeneration_required`: 객관적 운율 또는 문장 경계 실패
- `awaiting_audio_listening_qc`: 객관적 운율은 통과했지만 실제 오디오 A/B 3회 증거 없음
- `awaiting_user_listening_approval`: STT·정렬·운율·실제 오디오 A/B 3회 완료, 사용자 청취 전
- `user_approved_final`: 모든 문장 및 전체 미리보기 승인, 최종본 생성
- `user_delegated_auto_qc_final`: 사용자가 청취를 명시적으로 생략하고 강화 자동 QC 기반 최종화를 위임해 최종본 생성

어떤 실패 상태도 `user_approved_final`이나
`user_delegated_auto_qc_final`로 자동 승격하지 않는다.
