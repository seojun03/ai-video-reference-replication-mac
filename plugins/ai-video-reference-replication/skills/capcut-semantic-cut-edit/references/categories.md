# 분야별 화면 연출 선택

[제품 종류 인터뷰](visual-direction.md)로 종류가 확정된 뒤 해당 분야만 적용한다. 이 자료는 **클린본의 장면 선택·배치·구도**만 다룬다. 공통 자막·음성·호흡·무음·싱크·컷 기준은 변경하지 않는다.

| 선택·분야 | 우선 보여줄 화면 | 문맥에 직접 맞는 소스가 없을 때 | 구도 판단 |
|---|---|---|---|
| 1. 건기식 `supplement` | 사용자 대본의 실제 제형과 복용/사용 방식, 해당 제품 디테일 | 먹는 제품은 섭취 `eating`; 바르는 제품은 도포 `application` | 실제 사용 행동과 해당 제품이 연결되어 보이게 |
| 2. 뷰티 `beauty` | 바르는 장면 중심. 얼굴용 제품은 얼굴에 바르기·펴 바르기, 문맥에 맞는 제형·제품 컷 | 실제 도포 장면 `application` | 손·제품·도포 부위가 잘리지 않게; 라벨만 보이는 장면을 도포라고 판정하지 않음 |
| 3. 식품 `food` | 먹는 장면·제품 컷 중심. 문맥에 맞는 붓기·집기·쪼개기·질감·포장·공정도 선택 | 같은 제품을 먹는 장면 `eating` | 먹기는 손·입·제품 관계, 제품 컷은 음식 디테일, 공정은 필요한 작업 맥락 |
| 4. 그외 `other` | 이번 대본과 제공 소스의 실제 제품 사용·조작·시연, 제품 디테일 | 같은 제품의 실제 사용 `product_use`; 명시된 섭취/도포 제품이면 해당 행동 | 제품·손·조작 대상·사용 결과 등 문장에 필요한 관계가 보이게 |

장면 종류의 비율을 임의 수치로 고정하지 않는다. 이번 대본 문맥과 실제 클린본의 표현력을 보고 고른다. 직접 문맥이 맞는 제품 컷과 사용 행동 대체 컷을 구분하고, 포장만 보이는 장면을 먹기/바르기로 기록하지 않는다.

건기식이라고 무조건 같은 복용 동작을 쓰지 않는다. 실제 사용자 대본·제품 형태를 따른다. 물에 타 마시는 경우도 섭취 계열로 분류하되 관찰 기록에는 실제 행동을 구체적으로 적는다. 뷰티도 제품의 실제 사용 부위를 따른다. 영상에 없는 행동·신체 변화 장면을 만들어 넣지 않는다.

그외는 식품/뷰티 프로필의 별칭이 아니다. 같은 제품의 실제 관찰된 사용 행동을 구체적으로 기록하고, 소스에 없는 기능 시연이나 결과를 봤다고 쓰지 않는다. 해당 장면이 없으면 공통 미충족 구간 규칙을 적용한다. `product_use`는 `other`에서만 쓰며 기존 식품의 섭취 등 분야별 행동 조건을 약화하지 않는다.

## 저장된 화면 프로필

| 분야 | 적용 자료 | 현재 상태 |
|---|---|---|
| 건기식 | 위 사용자 지정 화면 원칙 | 승인 타임라인 사례 미등록 |
| 식품 | [food-nuttybutty-01/visual-v2 — 너티버티 호두정과, 타임라인 11 첫 영상](food-nuttybutty-01.md) | 승인 사례에서 추출한 화면 규칙 등록 |
| 뷰티 | 위 사용자 지정 도포 중심 화면 원칙 | 승인 타임라인 사례 미등록 |
| 그외 | 위 실제 제품 사용·시연 중심 일반 원칙 | 승인 타임라인 사례 미등록 |

식품 선택 후에는 등록된 프로필을 불러오며 원본 승인 타임라인을 다시 찾거나 재지정받지 않는다. 뷰티/건기식은 일반 원칙이 있다는 것과 승인 타임라인 학습이 끝났다는 것을 혼동하지 않는다. 사례 미등록만으로 매번 기준 타임라인을 요청하지 않는다.

새 사례를 학습할 때는 [화면 전용 학습 범위](visual-direction.md)에 따라 정확한 승인 범위와 시각 증거, 장면 우선순위·문맥별 배치·구도만 해당 분야 파일에 저장한다. 공통 컷·자막·음성 규칙이나 실행기는 수정하지 않는다.
