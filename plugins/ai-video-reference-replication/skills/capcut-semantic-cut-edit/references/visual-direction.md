# 제품 종류 인터뷰와 화면 전용 프로필

구조: **기존 공통 컷편집 + 분야별 화면 연출 규칙**. 학습은 승인 타임라인의 클린본 장면 선택·배치·구도를 재사용 가능한 문서로 저장하는 일이다. 모델 가중치 재학습이나 영상 전체 복제가 아니다.

## 1. 실제 편집의 첫 접수

| 현재 요청 | 첫 행동 |
|---|---|
| 스킬 설명·수정·학습 자료 등록 | 요청한 지침/학습 작업만 한다. 실제 영상 편집용 인터뷰나 편집을 시작하지 않는다. |
| 기존 화면을 유지하는 자막 싱크·무음 정리만 | 일반 컷편집을 유지한다. 제품 프로필이나 화면 변경용 인터뷰를 끼워 넣지 않는다. |
| 새 제품 영상·클린본 장면 배치·유형이 정해지지 않은 컷편집 호출 | 아래 제품 종류를 먼저 확인하고 해당 분야의 화면 규칙을 연결한다. |

접수 선택값은 다음과 같다. 번호는 이 제품 종류 질문에 대한 응답일 때만 해석한다.

| 선택 | 제품 종류 | 계획의 `category` |
|---|---|---|
| 1 | 건기식 | `supplement` |
| 2 | 뷰티 | `beauty` |
| 3 | 식품 | `food` |
| 4 | 그외 | `other` |

- 이번 요청이나 이번 작업의 앞선 답변에서 사용자가 종류를 직접 선택했다면 접수된 것으로 보고 중복 질문하지 않는다.
- 상위 제작 스킬의 `production_intake.capcut.category`와 실제 답변 원문도 이번 작업의 직접 선택이다. `2 → beauty` 등 정규화 결과를 그대로 쓰며 분야 질문을 다시 하지 않는다. 이전 메뉴로 수집한 정규화된 `food`/`beauty` 값을 현재 번호표로 다시 해석하지 않는다.
- 직접 선택이 없다면 첫 질문은 **어떤 종류의 제품인지** 하나만 확인한다. 실행 환경의 질문 도구·대화 규칙에 맞춰 위 선택값을 안내하고 응답을 기다린다. 선택형 질문을 지원하지 않는 환경에서는 제품 종류만 묻는 짧은 질문으로 확인한다.
- 호두정과·세럼 등 제품명, 파일명, 썸네일, 과거 업체 분류로 사용자의 선택을 대신하지 않는다. 종류를 받기 전에 프로필을 선택하거나 자료 분석·편집 준비를 시작하지 않는다.
- 선택이 모호하면 그 종류만 확인한다. 제품 종류가 정해진 후에야 자료·제품명·음성 종류·저장 프로젝트 중 실제 빠진 값만 확인한다. 이미 받은 자료를 다시 요구하지 않는다.
- 접수된 종류를 `plan.category`에 사용하고, 현재 작업 메모에 적용한 화면 프로필과 그 상태를 남긴다. 계획 형식이나 공통 편집 기준을 새로 만들지 않는다.

## 2. 규칙의 소유권

| 영역 | 유일한 기준 | 제품 종류가 바꿀 수 있는 것 |
|---|---|---|
| 자막·음성·호흡·무음·싱크·공통 컷 | [capcut-cut-edit](../../capcut-cut-edit/SKILL.md) | 없음 |
| 클린본 화면 | [분야별 선택 기준](categories.md)과 선택 분야 프로필 | 행동/제품 장면의 우선순위, 문맥별 배치, 구도·프레이밍 판단 |
| 공통 화면 한도 | [문맥별 스킬의 장면·구간 규칙](../SKILL.md) | 한도를 지키며 선택 구간·보정값을 결정 |
| 안전 저장 | [기존 실행 연결](execution.md) | 없음 |

분야를 바꿔도 자막 문구·분할·폰트·위치·타이밍, 무음/호흡 처리 수치, 음성 속도·피치, 의미구와 발화에 맞추는 컷 기준은 그대로다. 프로필에 이런 설정을 넣거나 공통 규칙을 별도 복사해 재정의하지 않는다.

## 3. 승인 타임라인에서 저장할 내용

사용자가 해당 사례의 학습/기준 반영을 요청했을 때만 분야 자료를 갱신한다. 한 번 추출한 프로필은 다음 작업에 그대로 불러오며 승인 타임라인을 매번 재확인하지 않는다.

화면 프로필의 내용은 아래 범위로 한정한다.

| 항목 | 저장 내용 |
|---|---|
| 식별·승인 출처 | 분야, 프로필 ID/버전, 승인 상태, 정확한 업체·제품·타임라인과 승인된 영상 범위 |
| 장면 우선순위 | 먹기·바르기·제품 디테일 등 어떤 화면을 우선 보여주는지 |
| 문맥별 배치 | 대본의 어떤 의미에 어떤 실제 행동/제품/공정 장면을 연결하는지 |
| 구도 | 제품·손·입·얼굴·사용 부위 중 무엇을 중심에 두고 어느 대상을 함께 보여주는지 |
| 시각 증거·제외 범위 | 실제 확인한 클린본 구간/프레임, 제외한 배리에이션과 적용 범위 |

자막·음성·호흡·무음·공통 컷 타이밍은 학습 항목이 아니다. 승인 타임라인의 자막 통계·경계·디자인, 음성 배속·쉼 길이, 컷 개수·절대 시간은 프로필의 지침으로 저장하지 않는다. 컷 사이 효과·전환·BGM도 가져오지 않는다. 화면 점유율·클립별 길이를 고정 수치로 추정해 추가하지 않는다.

추출할 때는 사용자가 지정한 완성 영상 범위의 화면만 읽기 전용으로 분석하고, 실제 관찰한 장면 판단을 해당 분야 파일에 기록한다. 단순히 새 예시를 받거나 학습 후보를 분석한 것은 사용자 승인을 대신하지 않는다. 승인 범위가 명시되면 그 범위를 따르고, 후보 분석만 요청됐다면 후보로 남긴다.

학습 업데이트 대상은 **해당 분야 화면 프로필과 그 목록**뿐이다. 공통 스킬의 컷/자막 본문, 실행 스크립트, 원본·기존 타임라인에는 쓰지 않는다. 공통 기준 변경은 별도의 명시적인 요청에서만 다룬다.

## 4. 새 영상에 적용

1. 사용자 선택으로 확정한 분야의 저장된 화면 규칙을 불러온다. 다른 분야의 사례나 다른 업체의 제품 사실·미디어를 가져오지 않는다.
2. 기존 공통 컷편집이 정한 의미 구간·최종 음성·자막 시각에 맞춰 **이번 제품의 새 클린본을 실제로 확인**한다. 승인 타임라인을 다시 보지 않는 것과 새 클린본을 보지 않는 것은 다르다.
3. 해당 의미를 잘 표현하는 원본 구간과 구도를 골라 기존 계획의 `clips`에 배치한다. 프로필이 정하는 것은 화면의 소재·선택 이유·원본 구간·프레이밍이며, 공통 음성/자막 시간이나 컷 기준을 프로필에 맞춰 바꾸지 않는다.
4. 저장·싱크·음성·자막 검수는 기존 실행 경로를 그대로 사용한다. 화면 선택 때문에 기준을 바꾸거나 검사를 우회하지 않는다.

선택한 분야에 승인 타임라인 프로필이 아직 없으면 [분야별 사용자 지정 화면 원칙](categories.md)을 적용하고 **승인 사례 미등록**임을 구분한다. 다른 분야 프로필로 대체하거나 학습 완료를 꾸미지 않는다. 매 작업마다 기준 타임라인 제출을 요구하지 않는다.

저장용 `source_id`는 이번 업체 프로젝트의 기술 형식 연결일 뿐 화면 학습 자료가 아니다. 도구가 현재 프로젝트 안에서 자동 연결하므로 기준 타임라인 이름이나 새 타임라인 생성 지시·이름을 필수 입력으로 요구하지 않는다. 원본 승인 타임라인의 이름·경로가 바뀌어도 저장된 화면 규칙 자체는 유지된다.

예: 제품 종류를 따로 선택하지 않은 “$capcut-cut-edit로 너티버티 호두정과를 편집해줘. 대본·클린본·TTS를 첨부했어”에는 **제품 종류 질문이 먼저**다. 위 질문에 “3”이라고 답하면 식품 화면 프로필을 연결한다. 상위 초반 인터뷰에서 이미 “2. 뷰티”를 골랐다면 질문 없이 뷰티로 진행한다. 자막·호흡·무음·컷편집과 새 타임라인 생성은 기존 기준대로 진행한다.
