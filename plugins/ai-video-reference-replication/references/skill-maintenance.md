# 소유자 스킬 수정은 공개 배포까지

소유자의 2026-09-08 명시 지시: “스킬 수정하면 무조건 배포본에 반영 되도록 해줘”. 이 플러그인과 포함된 지원 스킬의 소유자 유지보수 요청에만 적용한다. 영상 제작 요청, 읽기 전용 진단, 다른 플러그인, 수신자 개인 수정에는 배포를 시작하지 않는다. 최신 사용자가 로컬 시험만 요청하거나 배포를 금지하면 해당 제한이 우선한다.

1. 원본은 `~/plugins/ai-video-reference-replication`이다. 설치 캐시의 버전 경로를 사용자가 가리켜도 원본의 대응 파일을 수정한다. 소유자 배포 설정 `~/.codex/state/ai-video-reference-replication/publisher.json`의 활성 상태와 지정 저장소만 확인한다. 설정·인증값을 생성하거나 수정하지 않는다. 수신자 환경에서는 소유자 저장소에 배포하지 않는다.
2. 요청한 변경과 직접 관련된 검증만 수행한다. 캐시를 직접 덮어쓰거나 배포 저장소 사본만 고치지 않는다. 유지보수 중 제작 인터뷰·유료 영상 생성·CapCut 종료를 시작하지 않는다.
3. 수정 후 `python3 ~/plugins/ai-video-reference-replication/scripts/refresh_plugin.py`를 반드시 실행한다. 이 명령은 버전 관리, 로컬 설치, 테스트, 지정 저장소 동기화, 해당 커밋의 macOS CI, 공개 릴리스, 공개 자산 재다운로드와 해시 비교까지 담당한다. 같은 대상의 배포를 다시 승인받지 않는다. 명시적인 로컬 시험 요청에만 `--local-only`를 사용하고 배포 미완료로 보고한다.
4. 공개 배포 성공에는 현재 원본 버전과 `last-published.json`의 버전 일치, 해당 커밋의 CI 성공, 네 설치 자산의 재다운로드 해시 일치가 필요하다. 공개 플러그인 ZIP 안에 이번 수정이 들어 있는지도 확인한다. 로컬 설치 캐시가 원본과 일치하는지 확인한 뒤 새 작업에서 적용됨을 안내한다. 실제 수신자 PC 업데이트는 별도 확인 전까지 완료했다고 말하지 않는다.
5. 배포 실패·설정 누락·CI 실패를 로컬 성공으로 바꾸지 않는다. 실패 단계와 남은 조치를 보고한다. 완료 기록이 없으면 수정 작업은 배포 미완료다. 재실행 전 현재 릴리스 상태를 확인하고 기존 게시물이나 사용자 자료를 삭제하지 않는다.

이 절차는 에이전트가 수정 요청을 처리할 때의 완료 조건이다. 파일을 저장하는 즉시 게시하는 상시 감시기가 아니며, 별도 감시기나 예약 작업을 만들지 않는다. 키·토큰·제품 자료·CapCut 프로젝트는 배포에 포함하지 않는다.
